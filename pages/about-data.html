About the Data

Where the data comes from, what it means, and how it is kept up to date.

Data Source

All hospital quality data displayed on this platform is sourced from Kementerian Kesihatan Malaysia (KKM) — the Ministry of Health Malaysia.

The data includes HPIA (Hospital Performance Indicator Assessment), CliSQI, Cluster Performance, MyPSQ/PSQ-18 patient satisfaction, and Casemix indicators collected and published by KKM as part of its hospital performance monitoring programme.

📋 Official source: Kementerian Kesihatan Malaysia (KKM) Hospital Performance Data.
This platform presents KKM data in a UI/UX-friendly format.

Reporting Period

Each hospital record shows the reporting year for which data is available. Not all hospitals have data for the same year — some may have more recent data, others may be pending submission.

The reporting year is displayed on every hospital page:

  • Data year — the year to which the performance data relates
  • Last updated — when this record was last updated in the dataset

This platform never presents old data as if it were current. Where data is from a prior period, the year is always shown.

What the Data Does and Does Not Show

What it shows

  • Hospital performance across standardised KKM indicators
  • Patient-reported satisfaction from the MyPSQ/PSQ-18 survey
  • Clinical services quality from CliSQI
  • Cluster collaboration performance
  • Casemix complexity and resource performance

What it does not show

  • Individual patient records or outcomes
  • Real-time bed availability or waiting times
  • Private hospital data
  • Guarantee of individual clinical outcomes
  • Emergency triage capability or response times
⚠️ This is not medical advice. Hospital performance indicators support informed comparison and should not be used as the sole basis for hospital selection. In an emergency, contact 999 or go to your nearest emergency department immediately.

Missing Data

Not all hospitals have complete data for every indicator. This may be because:

  • The hospital did not submit data for that indicator in the current reporting period
  • The indicator is not applicable to that hospital type
  • Data collection is in progress
  • Data has been suppressed due to small numbers

Missing values are never shown as zero. The platform uses clear labels: Not available, Not applicable, Pending, etc. See the Data Quality section of the Methodology page for full definitions.

Source Data vs Displayed Data

This platform distinguishes between:

  • Source data — the original values from the KKM dataset (e.g. an official score of 4.52)
  • Displayed data — how values are formatted for readability (e.g. displayed as 4.5 / ★★★★½)

Where an authoritative overall score is supplied by KKM, that official score is used. Calculated composite scores are only used where KKM has not provided one.

Limitations

  • Hospital performance data reflects aggregated institutional performance, not individual clinician quality
  • Rankings and comparisons are based on the available dataset and reporting year
  • Some hospitals may not have reported for the most recent year
  • Patient satisfaction data reflects survey respondents and may not represent all patients
  • Casemix data should be interpreted relative to hospital type and case complexity, not as an absolute quality measure
